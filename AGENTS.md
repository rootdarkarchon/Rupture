# Packaging and deployment

- Package only runtime files and required third-party license notices. Do not include documentation, handoff files, reports, or other extras unless the user explicitly requests them.
- Use only `scripts/Build-Package.ps1` to generate release or deployment ZIPs. Run its required build and validation prerequisites first.
- Use the script's canonical output unchanged: `artifacts/Rupture-<version>-<githash>.zip`.
- Never create release archives manually, rename or copy them under alternate names, or append fix labels, dates, suffixes, or any other addendums.
- When handing off or deploying a build, use the canonical ZIP generated by that script.
